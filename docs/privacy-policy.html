Política de Privacidade — MediaTrack

Última atualização: 23 de setembro de 2026

Esta política descreve que dados o MediaTrack recolhe e como são usados. O MediaTrack é uma app pessoal/familiar de acompanhamento de filmes, séries, animes, mangas e livros.

1. Dados que recolhemos

E-mail, para criar a tua conta e enviar o código de acesso (login sem password). Biblioteca pessoal: os títulos que adicionas, o estado, progresso e as tuas classificações/reviews.

Não recolhemos localização, contactos, fotos, nem dados de pagamento — a app não tem compras nem anúncios.

2. Como usamos os dados

Exclusivamente para autenticar-te, guardar e mostrar a tua biblioteca entre dispositivos, e (se ativares) enviar-te lembretes locais no teu próprio telefone. Não vendemos nem partilhamos dados com terceiros para publicidade.

3. Onde os dados ficam guardados

Numa base de dados Supabase (PostgreSQL), protegida por Row Level Security. A sessão de acesso é guardada de forma encriptada no dispositivo (Keychain/Keystore).

4. Serviços de terceiros

Ao pesquisares um título, a app consulta APIs públicas — TMDB, AniList e Open Library — apenas para obter informação pública sobre esse título.

5. Bloqueio por biometria

A verificação por Face ID / impressão digital / PIN é feita inteiramente pelo sistema operativo do teu telemóvel — a MediaTrack nunca recebe nem guarda dados biométricos.

6. Os teus direitos

Podes pedir a eliminação da tua conta e dados a qualquer momento, contactando SUBSTITUI-PELO-TEU-EMAIL.

7. Menores de idade

O MediaTrack não é direcionado a crianças menores de 13 anos.
